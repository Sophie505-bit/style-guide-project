# Глоссарий

Термины, используемые в руководстве. Если термин встречается в документации
организации, используйте написание из этой таблицы.

| Термин | Значение |
| --- | --- |
| ADR | Architecture Decision Record — документ с описанием и обоснованием архитектурного решения |
| CI/CD | Непрерывная интеграция и непрерывная доставка: автоматические проверки и деплой |
| Conventional Commits | Соглашение об оформлении сообщений коммитов вида `docs(раздел): описание` |
| Docs-as-code | Подход, при котором документация хранится и обрабатывается как код |
| Frontmatter | Блок метаданных в начале Markdown-файла между тройными дефисами |
| How-to | Инструкция по решению конкретной задачи |
| Linter | Инструмент автоматической проверки текста или кода по правилам |
| MkDocs | Генератор статических сайтов документации из Markdown |
| Pull Request | Запрос на слияние изменений из ветки в основную ветку |
| Reference | Справочный раздел документации с полным описанием параметров или API |
| SemVer | Semantic Versioning — версионирование вида «major.minor.patch» |
| Reviewer | Участник ревью, проверяющий Pull Request |
| Стайлгайд | Руководство по стилю — настоящий документ |
| Дизамбигуация | Устранение неоднозначности формулировки |
