# Справочник API

Справочник описывает каждый эндпоинт полностью и единообразно: читатель должен
получить ответ на любой вопрос о методе, не открывая код.

## Структура описания эндпоинта

1. **Назначение** — одно предложение, что делает метод.
2. **Метод и путь** — `POST /v1/orders`.
3. **Аутентификация и права** — какой токен, какая роль, какие scope.
4. **Параметры пути и запроса** — таблица.
5. **Тело запроса** — JSON-пример + таблица полей.
6. **Пример запроса** — `curl`, готовый к копированию.
7. **Пример ответа** — успешный ответ целиком.
8. **Коды ответов** — таблица: код, значение, когда возвращается.
9. **Ограничения** — rate limit, размер тела, таймауты.
10. **Связанные методы** — ссылки.

## Таблицы параметров

Обязательные колонки: имя, тип, обязательность, описание, значения
по умолчанию и допустимые значения.

| Параметр | Тип | Обязательный | Описание | По умолчанию |
| --- | --- | --- | --- | --- |
| `limit` | integer | нет | Размер страницы, от 1 до 100 | `20` |
| `status` | string | нет | Фильтр по статусу: `new`, `paid`, `cancelled` | — |

Правила:

- Имена полей — точно как в API, в инлайн-коде. **MUST**
- Для каждого кода ошибки — причина и способ устранения. **MUST**
- Примеры согласованы между методами: один и тот же сущностный объект
  в примерах не меняет идентификаторы и поля без пояснений. **SHOULD**

## Пример описания

### Создание заказа

Создаёт заказ и резервирует товар на складе.

`POST /v1/orders`

Требуется токен с ролью `operator`.

Запрос:

```bash
curl -X POST https://api.example.com/v1/orders \
  -H "Authorization: Bearer <токен>" \
  -H "Content-Type: application/json" \
  -d '{"sku": "SKU-001", "quantity": 2}'
```

Успешный ответ (`201 Created`):

```json
{
  "id": "ord_7f3a91",
  "sku": "SKU-001",
  "quantity": 2,
  "status": "new",
  "created_at": "2026-10-12T09:30:00Z"
}
```

| Код | Значение | Когда возвращается |
| --- | --- | --- |
| `201` | Заказ создан | Успешное создание |
| `400` | Некорректный запрос | Нет поля `sku` или `quantity` меньше 1 |
| `401` | Не авторизован | Токен отсутствует или просрочен |
| `409` | Конфликт | Товара нет на складе в нужном количестве |
