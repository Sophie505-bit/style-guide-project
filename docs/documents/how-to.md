# Инструкции (how-to)

Инструкция отвечает на вопрос «как сделать X». Хорошая инструкция позволяет
читателю выполнить задачу, не задавая вопросов автору.

## Обязательная структура

1. **Заголовок** — в форме «Как …» или «Настройка …»: «Как настроить деплой».
2. **Предназначение** — 1–2 предложения: для кого инструкция и что получится
   в результате.
3. **Предпосылки** — что должно быть готово до начала: права, доступы,
   установленное ПО и его версии, входные данные.
4. **Шаги** — нумерованный список действий.
5. **Проверка результата** — как убедиться, что всё сработало.
6. **Возможные проблемы** — частые ошибки и их решение (если известны).
7. **Связанные материалы** — ссылки на сопутствующие документы.

## Правила шагов

- Один шаг — одно действие. **MUST**
- Шаг начинается с глагола в повелительном наклонении: «Выполните»,
  «Откройте», «Проверьте». **MUST**
- Команды и параметры — в инлайн-коде, кнопки — **жирным** как в интерфейсе. **MUST**
- После ключевого шага — ожидаемый результат: «В терминале появится
  сообщение `Build succeeded`».
- Не используйте «и т. д.», «по аналогии», «остальное настройте сами» —
  инструкция должна быть полной. **SHOULD**
- Скрытых действий нет: если нужно переключить вкладку или повысить права —
  это отдельный шаг. **SHOULD**

## Пример хорошей инструкции

```text
# Как запустить локальную сборку документации

Инструкция для авторов документации. После выполнения на компьютере появится
локальный сайт с предпросмотром изменений.

## Предпосылки

- Python 3.12 или новее;
- доступ к репозиторию style-guide-project.

## Шаги

1. Склонируйте репозиторий:

   git clone git@github.com:Sophie505-bit/style-guide-project.git

2. Создайте виртуальное окружение и установите зависимости:

   python -m venv .venv && pip install -r requirements.txt

3. Запустите локальный сервер:

   mkdocs serve

   В терминале появится строка Serving on http://127.0.0.1:8000.

## Проверка результата

Откройте http://127.0.0.1:8000 — откроется сайт документации.
Изменения в файлах применяются автоматически после сохранения.

## Возможные проблемы

- Порт 8000 занят: запустите mkdocs serve -a localhost:8001.
```

## Чек-лист

- [ ] Предпосылки полны (права, доступы, версии)
- [ ] Каждый шаг — одно действие с глаголом в повелительном наклонении
- [ ] Описан ожидаемый результат
