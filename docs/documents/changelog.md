# Журнал изменений

CHANGELOG.md ведётся по формату [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [SemVer](https://semver.org/lang/ru/).

## Правила

- Файл называется `CHANGELOG.md` и лежит в корне репозитория. **MUST**
- Записи на русском языке, в прошедшем времени: «Добавлен экспорт в CSV». **MUST**
- Дата релиза — ISO 8601: `## [2.4.0] - 2026-10-12`. **MUST**
- Ссылка на сравнение версий — внизу страницы. **SHOULD**
- Каждая запись дублирует ссылку на задачу или PR: `(#142)`. **SHOULD**
- Незарелизенные изменения живут в разделе `[Unreleased]`. **SHOULD**

## Разделы

| Раздел | Что попадает |
| --- | --- |
| Added | Новая функциональность |
| Changed | Изменения существующего поведения |
| Deprecated | Функциональность, которую планируется удалить |
| Removed | Удалённая функциональность |
| Fixed | Исправления ошибок |
| Security | Уязвимости и их исправление |

Пустые разделы не выводятся. **SHOULD**

## Шаблон

```markdown
# Журнал изменений

Формат — Keep a Changelog, версионирование — SemVer.

## [Unreleased]

### Added

- Экспорт отчётов в CSV (#142)

## [2.4.0] - 2026-10-12

### Added

- Фильтр заказов по статусу (#131)
- Значок статуса CI в README (#135)

### Fixed

- Исправлено падение при пустом поле `sku` (#138)

### Security

- Обновлён `cryptography` до 45.1.0 (#140)

[Unreleased]: https://github.com/OWNER/REPO/compare/v2.4.0...HEAD
[2.4.0]: https://github.com/OWNER/REPO/compare/v2.3.1...v2.4.0
```

## Чего не делать

- Не пересказывать весь код: запись отвечает на вопрос «что изменилось
  для пользователя».
- Не менять старые записи задним числом: выпускайте исправление.
- Не смешивать в одной записи разные изменения: «Много улучшений» — плохая
  запись.

## Чек-лист

- [ ] Версия и дата в формате `[X.Y.Z] - ГГГГ-ММ-ДД`
- [ ] Записи начинаются с глагола в прошедшем времени
- [ ] Есть ссылки на задачи/PR
- [ ] Обновлены ссылки сравнения версий внизу
