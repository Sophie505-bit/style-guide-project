# README

README — витрина репозитория: по нему читатель за 5 минут решает, нужен ли ему
проект, и запускает его локально. У каждого репозитория с кодом есть README.md
в корне. **MUST**

## Обязательная структура

1. **Название** — как называется проект.
2. **Назначение** — одно предложение: что проект делает и для кого.
3. **Значки статуса** — CI, версия, лицензия (badges).
4. **Требования** — версия языка, зависимости, права доступа.
5. **Установка** — команды от чистого окружения до запуска.
6. **Быстрый старт** — минимальный рабочий пример.
7. **Документация** — ссылка на полную документацию.
8. **Как внести вклад** — ссылка на CONTRIBUTING.md.
9. **Лицензия** — название и ссылка на файл LICENSE.

Порядок блоков 1–6 обязателен; остальные — рекомендуемы. **SHOULD**

````markdown
## Требования

- Python 3.12+
- PostgreSQL 16

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Быстрый старт

```bash
python app.py --config config.example.yaml
```

## Документация

- Руководство пользователя: https://docs.example.com
- Справочник API: https://docs.example.com/api

## Как внести вклад

См. [CONTRIBUTING.md](CONTRIBUTING.md).

## Лицензия

MIT — см. [LICENSE](LICENSE).
````

## Правила

- Первый абзац понятен человеку не из команды: без внутренних сокращений. **MUST**
- Пример из «Быстрого старта» выполняется копированием и работает. **MUST**
- Инструкция по установке проверена на чистом окружении не позднее последнего
  мажорного релиза. **SHOULD**
- Объём — до 150 строк; всё, что длиннее, переносится в документацию
  (ссылка из README). **SHOULD**
