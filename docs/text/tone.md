# Голос и тон

## Общий голос

Документация говорит спокойно, по делу и уважительно: помогает читателю,
не поучает и не развлекает.

- **Обращение к читателю** — на «вы», со строчной буквы: «вы», «ваш».
  Формулировка «Вы» с прописной не используется. **MUST**
- **Активный залог** вместо пассивного. **SHOULD**
- **Настоящее время** для описания поведения системы. **SHOULD**
- **Повелительное наклонение** для инструкций: «нажмите», «выполните». **MUST**
- Оценки, шутки и просторечия в справочной документации не используются.
  **SHOULD**

## Таблица замен

| Плохо | Хорошо |
| --- | --- |
| Осуществляется нажатие кнопки «Сохранить» | Нажмите **Сохранить** |
| Вами будет получено письмо | Вы получите письмо |
| Является обязательным условием | Требуется |
| В связи с тем, что | Так как |
| Данный документ описывает | Документ описывает |
| Работает корректно | Возвращает код 200 |
| Огромный, супербыстрый | 2 млн операций в секунду |

## Канцелярит и «ИИ-стиль»

Запрещены конструкции «является», «осуществляется», «производится»,
«в целях», «в рамках», а также шаблонные вводные фразы, особенно типичные
для текстов, сгенерированных нейросетями:

- «Важно отметить, что…» — просто удалить;
- «В современном мире…», «В заключение стоит сказать…» — удалить;
- «Данный подход позволяет обеспечить…» → «Подход обеспечивает…».

## Мы и система

- «Мы» допустимо в блоге и объявлениях об изменениях («мы добавили…»),
  недопустимо в справочной документации (**MUST**).
- Система не «хочет», не «думает» и не «предлагает»: она принимает запросы,
  возвращает ответы и хранит данные.
- Сообщения об ошибках в документации цитируются дословно и переводятся:
  «Ошибка `Invalid token` означает, что срок действия токена истёк».

## Тон в разных типах документов

| Тип документа | Тон |
| --- | --- |
| Инструкция (how-to) | Нейтрально-деловой, императивные шаги |
| Справочник API | Формальный, только факты |
| README | Краткий, дружелюбный |
| CHANGELOG | Нейтральный, прошедшее время |
| Пост о релизе | Дружелюбный, допустимо «мы» и эмодзи |
