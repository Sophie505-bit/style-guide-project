# Код и команды

## Инлайн-код

Внутри строки `моноширинный формат` используется для всего, что читатель
может скопировать или должен ввести дословно:

- имена файлов и путей: `docs/index.md`, `/etc/nginx/nginx.conf`;
- команды и утилиты: `git rebase`, `docker compose up`;
- флаги и параметры: `--verbose`, `-p 8080`;
- имена переменных, полей и значений: `user_id`, `timeout=30`;
- фрагменты кода: `dict.get(key)`.

Не оборачивайте в инлайн-код названия продуктов («Python», «Docker» — обычный
текст) и элементы интерфейса (для них — **жирный**).

## Блоки кода

- У блока кода всегда указывается язык: `bash`, `python`, `json`, `yaml`,
  `sql`, `text`. Без языка подсветка и копирование теряют смысл. **MUST**
- В командах не показывайте приглашение `$` или `C:\>`: читатель копирует
  строку целиком. Если нужно показать привилегии, укажите их в тексте. **MUST**
- Один блок — одно действие. Длинные команды переносятся через `\`.
- Комментарии внутри примера — только по делу и на русском.
- Вывод команды показывается отдельным блоком `text` и комментируется,
  если неочевиден.

## Плейсхолдеры

- Плейсхолдер — в угловых скобках: `git clone <url-репозитория>`.
  **SHOULD**
- Подстановка с реальным значением показывается в следующем примере.
- Плейсхолдеры пишутся строчными буквами через дефис: `<имя-ветки>`. **SHOULD**

## Примеры

Сравнение хорошего и плохого примера:

<!-- markdownlint-disable MD014 -->

Плохо — приглашение, нет языка, названия-заменители без пояснений:

```text
$ ./deploy.sh SERVER_NAME PROD<<< ??? см. в доке
```

<!-- markdownlint-enable MD014 -->

Хорошо — язык указан, плейсхолдер выделен, результат пояснён:

````markdown
```bash
./deploy.sh prod-01 production
```

```text
Запуск завершён успешно. Сборка доступна по адресу https://example.com
```
````

## Проверка примеров

- Пример должен быть рабочим при копировании: это проверяется при ревью. **MUST**
- Если пример учебный и не запускается — это указывается явно:
  «Пример иллюстративный, запустите его на тестовом стенде».
- Версии в примерах (`pip install requests==2.32.0`) фиксируются только там,
  где версия принципиальна. **SHOULD**
