# Заголовки, списки и таблицы

## Заголовки

- В документе ровно один заголовок первого уровня (`#`) — название документа.
  **MUST**
- Уровни вложены без пропусков: `#` → `##` → `###`. Переход `#` → `###`
  запрещён. **MUST**
- Заголовок формулируется кратко (до 60 символов) и не заканчивается точкой
  или двоеточием. **SHOULD**
- В русских заголовках — только первое слово с прописной:
  «Настройка интеграции», не «Настройка Интеграции». **SHOULD**
- Заголовок не дублирует название раздела-родителя.
- Заголовки уникальны в пределах страницы: одинаковые названия ломают
  якорные ссылки. **MUST**
- Для навигации по длинным документам должно хватать уровня `##` — не
  спускайтесь глубже `###` без необходимости. **SHOULD**

## Списки

- **Маркированный список** — неупорядоченное перечисление; **нумерованный** —
  последовательность действий, где важен порядок. **MUST**
- Элементы одного списка грамматически параллельны: либо все с глагола
  («Нажмите…», «Введите…»), либо все с существительного («Проверка…»). **SHOULD**
- Короткие элементы — без точки в конце, с прописной буквы. Если элемент
  содержит несколько предложений — пунктуация как в обычном тексте. **MUST**
- Вложенность — не глубже двух уровней. Три и более уровня — признак того,
  что список пора разбить на подразделы. **SHOULD**
- В нумерованных списках шагов подсписки-пояснения оформляются с отступом
  в 4 пробела.
- Пунктуация списка однородна во всём документе: либо везде точки, либо
  нигде (для коротких элементов — нигде).

## Таблицы

- Таблица используется для сравнений, наборов параметров, справки — не для
  связного текста и не для шагов инструкции. **SHOULD**
- Строка заголовков обязательна. **MUST**
- Каждая ячейка — короткая; если описание не влезает в одну строку исходника,
  сократите или вынесите текст под таблицу.
- Единицы измерения указываются в заголовке столбца: «Время, мс», а не
  в каждой ячейке.
- Пустая ячейка означает «неприменимо»; отсутствие данных обозначается «—». **SHOULD**

## Блоки примечаний

Для пояснений используйте блоки MkDocs Material, а не курсив и не скобки:

- `!!! note` — дополнительная информация;
- `!!! tip` — приём или рекомендация;
- `!!! warning` — риск потери данных или поломки;
- `!!! danger` — необратимые действия.

!!! tip "Пример"

    Если текст начинается со слов «Обратите внимание, что…», скорее всего
    ему нужен блок `!!! note`.
